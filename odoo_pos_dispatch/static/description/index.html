POS Dispatch & Delivery (Odoo 18)

A production-ready dispatch workflow for businesses that deliver orders created in Odoo POS. Backend-authoritative, POS-friendly, offline-safe, and receipt-integrated — built for restaurants, retail, and wholesale operations running in-house or assigned deliveries.

Odoo 18 Enterprise POS Dispatch Jobs Drivers & Vehicles Receipt Enhancements Offline POS Safe

Workflow

POS Order → Dispatch Job → Assign Driver / Vehicle → Track Delivery Status → Receipt (Dispatch Ref + Details)

Dispatch records are created on the backend and synced safely to POS. The receipt can print the dispatch reference and delivery details automatically.

Highlights

✅ Dispatch Job Automation

  • Automatic dispatch job creation for eligible POS orders
  • Database-enforced: one dispatch job per POS order
  • Safe relink logic if a job already exists

✅ Hardened Delivery States

  • Waiting → Assigned → En Route → Delivered
  • Failed / Cancelled terminal states
  • Guarded transitions to prevent invalid operations

✅ POS Receipt Enhancements

  • Print dispatch reference (e.g. DSP/00009)
  • Print order type (Delivery / Takeaway / Dine-In)
  • Print delivery details (name, phone, address, note)

✅ Backend-Authoritative, Offline-Safe

  • Server-side sequencing and reliable references
  • POS fetches dispatch reference after successful sync
  • Works with offline POS and deferred order sync

Technical Notes

Extends Odoo 18 POS using safe asset additions and OWL-compatible templates. No core files are overwritten. Dispatch logic is backend-driven for correctness in multi-session environments. 

Installation:
  1) Copy the module into your custom addons path
  2) Update Apps List
  3) Install "POS Dispatch & Delivery"
  4) Reload POS with ?debug=assets (one-time)
